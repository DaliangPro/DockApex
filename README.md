# Dock 文件夹（DockFolders）

**给 Mac 的 Dock 加上 iPhone 式的 App 文件夹。**

![Dock 文件夹：展开的分组面板与应用栏](docs/images/hero.png)

[English](README.en.md)

> 这是个人自用项目，只在作者的一台 Apple Silicon Mac（macOS 27.0.1，双显示器）上实测过。它用到多个未公开的系统接口，并会修改系统 Dock 的设置，系统升级后可能失效。使用前请先看“[注意事项](#注意事项)”。

## 为什么做它

macOS 的 Dock 不能把 App 收进文件夹。装的 App 一多，要么 Dock 越拉越长、图标越缩越小，要么只好把不常用的 App 移出去，用的时候再去启动台里翻。

Dock 文件夹用一条外观、手感都尽量贴近系统 Dock 的应用栏替换它，再加上 iPhone 那样的 App 分组：同一类 App 收进一个格子，一个位置放下好几个 App，点开就能用。

## 看看它的样子

![应用栏全貌](docs/images/bar.png)

左边是固定的 App 和分组，分组图标里显示组内 App 的缩略图；图标下方的小点表示正在运行；最右边是废纸篓。尺寸、间距和悬浮的玻璃底板按系统 Dock 校准。

## 主要功能

### iPhone 式分组

- **建组**：把一个 App 拖到另一个 App 图标的正中央，目标图标会长出文件夹底板并提示“松开创建分组”，松手就建好了。拖到图标边缘则是调整顺序。
- **打开**：单击分组，面板从图标上方展开，每行 3 个 App。单击其中的 App 就打开或切换过去；还没运行的 App 会在面板里跳动，启动后面板自动收起。
- **收起**：按 Esc、点面板外面，或者再点一次分组图标。
- **整理**：在面板里拖动排序；把 App 拖出面板，放回应用栏；右键分组可以重命名或解散。
- **不重复占位**：分组里的 App 运行时，分组图标下方会出现运行指示，不会在栏上再多出一个图标。

### 和系统 Dock 一样顺手

- 悬停放大（跟随系统 Dock 原来的“放大”设置）、运行指示、启动时弹跳、未读角标。
- 右键 App：打开／切换、在访达中显示、保留在应用栏或移除、隐藏、退出、强制退出。
- 拖动图标调整顺序；把图标拖出应用栏，看到“松开移出应用栏”时松手即可移除。
- 把文件或文件夹拖到应用栏空白处，会变成右侧的入口，单击文件夹可展开。
- 最小化的窗口显示在右侧。
- 废纸篓会显示空或满；右键可以打开，或者清倒（清倒前会先弹出确认框）。

### 窗口不会被挡住

系统 Dock 隐藏后，已经打开的 App 会以为屏幕底部没有 Dock，把窗口一直铺到最底下。Dock 文件夹会把铺满、平铺或伸进应用栏的窗口自动收短到应用栏上方，也会把伸进应用栏的小浮窗（比如语音输入条）挪开。双击标题栏缩放时，仍然可以在原尺寸和铺满之间来回切换。

### 多显示器与设置

右键应用栏空白处，或者点菜单栏的四格图标，可以设置：

- 管理分组、撤销布局更改
- 位置：底部、左侧、右侧
- 显示器：主显示器、指定显示器、所有显示器，或者跟随指针
- 自动隐藏、图标大小
- 显示最近使用的 App：关掉后，没固定的 App 退出就会从栏上消失

## 开始使用

### 1. 构建

需要 Apple Silicon、macOS 14 及以上、Xcode 命令行工具（Swift 6）和 Python 3。

```bash
git clone https://github.com/DaliangPro/DockFolders.git
cd DockFolders
bash build.sh
```

想先跑一遍测试：

```bash
swift test -c release --scratch-path build/tests --cache-path build/package-cache
```

### 2. 打开

```bash
open build/DockFolders.app
```

打开后，系统 Dock 会自动隐藏，应用栏出现在屏幕底部，原来 Dock 里的固定 App 会直接带过来。

### 3. 授权

在“系统设置 › 隐私与安全性”里打开下面几项：

| 权限 | 用途 |
| --- | --- |
| 辅助功能 | 窗口让位、浮窗避让、菜单等 |
| 屏幕录制 | 只有“影子 Dock”等可选功能才用 |
| 自动化 › 访达 | 清倒废纸篓，第一次使用时才会询问 |

### 4. 退出

点菜单栏的四格图标，或者右键应用栏空白处，选“退出”。退出时会自动恢复系统 Dock。

## 常见问题

**原来的系统 Dock 去哪了？**
被设为自动隐藏，并挪到应用栏所在的屏幕，所以最小化窗口时仍会缩向屏幕底部。退出 Dock 文件夹时，它会恢复原样。

**万一应用卡住或异常退出，怎么恢复原来的 Dock？**
双击项目目录里的 `RestoreDock.command`。它不依赖主应用界面和辅助功能权限，会恢复系统 Dock 的设置和系统预留区。

**窗口为什么会自己变矮一截？**
这是“窗口让位”：把伸到应用栏下面的窗口底边收到应用栏上方，避免被挡住。新打开的 App 有时会先铺满、再被收短。

**没固定的 App 退出后，图标还留在栏上？**
那是“最近使用的 App”。右键应用栏空白处，取消勾选“显示最近使用的 App”即可。

**分组和设置存在哪里？**
项目目录下的 `Data/`，包括分组、固定项顺序和偏好，不会上传到任何地方。请保留项目目录，不要单独挪走应用包。

**还有别的显示方式吗？**
可以改用“影子 Dock”：系统 Dock 保持显示，负责屏幕占位和最小化动画的终点，应用栏叠在它上面。需要屏幕录制权限，用来在应用栏下方补画背景。

```bash
defaults write io.daliang.dockfolders useShadowDock -bool true
```

改完重启应用生效。

## 注意事项

- 应用会修改系统 Dock 的设置（自动隐藏、图标尺寸、固定项等），改之前会记下原值，退出时恢复。请尽量通过“退出”正常退出。
- 运行时有两个随主应用一起退出的恢复助手；不安装登录项，也不安装后台常驻服务。
- 用到的未公开系统接口包括系统 Dock 占位区（SkyLight）、CoreDock、辅助功能窗口编号等，macOS 升级后可能失效。

## 已知限制

- 系统预留区只能登记一块屏幕；“所有显示器”模式下，其他屏幕靠窗口让位来补。
- 已经打开的 App 读不到应用栏的占位，窗口只能事后收短，会先错后对。
- App 自带的 Dock 菜单项还没有接入；部分自绘的 Dock 图标，以及全屏、多桌面的各种组合还没有全部覆盖。
