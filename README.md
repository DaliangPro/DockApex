# Dock 文件夹（DockFolders）

一个替代 macOS 系统 Dock 的自制应用栏：外观与交互尽量对齐系统 Dock，并加入 iPhone 式的 App 分组。

> 这是个人自用项目，只在作者的一台 Apple Silicon Mac（macOS 27.0.1，双显示器）上实测过。它用到多个未公开的系统接口，并会修改系统 Dock 的设置，系统升级后可能失效。使用前请先阅读“风险与恢复”。

## 功能

- **应用栏**：固定 App、运行中 App、文件与文件夹、下载、废纸篓；悬停放大、运行指示、未读角标、右键菜单（打开／切换、隐藏、退出、窗口列表等），按系统 Dock 的尺寸校准。
- **App 分组**：把 App 拖到另一个 App 图标中央即建组；单击分组展开（每行三个），单击成员打开或切换；分组里正在运行的 App 不再另占位置。
- **窗口让位**：系统 Dock 隐藏后，已运行的 App 会按“底部没有 Dock”摆放窗口。应用栏用辅助功能把铺满、平铺或伸进应用栏的窗口收短，并挪开伸进应用栏的小浮窗；双击标题栏缩放仍可在原尺寸与铺满之间切换。
- **显示器**：主显示器、指定显示器、所有显示器或跟随指针；位置可选底部、左侧、右侧，可自动隐藏。
- **其他**：废纸篓右键可清倒（先弹确认框，再交给访达执行）；可关闭“显示最近使用的 App”，让没固定的 App 退出后即从栏上消失；启动器类 App（如分组里放的是安装器、运行的是另一主程序）按同一个 App 显示。

## 工作方式

默认使用“经典模式”：让系统 Dock 自动隐藏并挪到应用栏所在的屏幕（最小化动画仍落向那里），应用栏显示在其上。也可改用“影子 Dock”：系统 Dock 保持显示负责占位与最小化终点，应用栏覆盖其上：

```bash
defaults write io.daliang.dockfolders useShadowDock -bool true
```

改完重启应用生效。影子 Dock 需要屏幕录制权限，用于在应用栏下方补画背景。

## 构建与运行

需要 Apple Silicon、macOS 14 及以上、Xcode 命令行工具（Swift 6）和 Python 3。

```bash
bash build.sh
swift test -c release --scratch-path build/tests --cache-path build/package-cache
open build/DockFolders.app
```

构建产物在 `build/DockFolders.app`，使用本机临时签名。分组、固定项和偏好保存在项目目录的 `Data/`（不入库），所以请保留项目目录，不要单独挪走应用包。

首次运行需要在“系统设置 › 隐私与安全性”中授权：

| 权限 | 用途 |
| --- | --- |
| 辅助功能 | 窗口让位、浮窗避让、窗口列表与菜单 |
| 屏幕录制 | 仅影子 Dock 等可选功能使用 |
| 自动化 › 访达 | 清倒废纸篓（第一次使用时询问） |

## 风险与恢复

- 应用会修改系统 Dock 的设置（自动隐藏、图标尺寸、固定项等），修改前记录原值，退出时恢复。请用菜单栏图标里的“退出”正常退出。
- 若应用异常退出或界面不可用，双击项目根目录的 `RestoreDock.command`，它不依赖主应用界面或辅助功能权限，会恢复系统 Dock 配置和系统预留区。
- 运行时有两个随主应用退出的恢复助手；不安装登录项或后台 LaunchAgent。
- 用到的未公开接口包括系统 Dock 占位区（SkyLight）、CoreDock 与辅助功能窗口编号等，系统升级后可能失效。

## 已知限制

- 系统预留区只能登记一个屏幕；“所有显示器”模式下其他屏幕靠窗口让位补充。
- 已运行的 App 读不到应用栏占位，窗口只能事后收短，会先错后对。
- App 自带的 Dock 菜单项尚未接入；部分自绘 Dock 图标、全屏与 Spaces 组合尚未全部覆盖。
