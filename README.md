# DockApex

**App 再多，一个 Dock 也装得下。**

![DockApex：展开的分组面板与应用栏](docs/images/hero.png)

[English](README.en.md)

DockApex 是一条替代 macOS 系统 Dock 的应用栏：外观、尺寸和手感按系统 Dock 校准，再加上 iPhone 那样的 App 分组。同一类 App 收进一个格子，一个位置放下好几个 App，点开就能用。

## 为什么做它

macOS 的 Dock 不能把 App 收进文件夹。装的 App 一多，要么 Dock 越拉越长、图标越缩越小，要么只好把不常用的 App 移出去，用的时候再去启动台里翻。DockApex 想让 Dock 既装得下，又保持原来的样子和用法。

## 看看它的样子

![应用栏全貌](docs/images/bar.png)

左边是固定的 App 和分组，分组图标里显示组内 App 的缩略图；图标下方的小点表示正在运行；最右边是最小化的窗口和废纸篓。图标尺寸、间距和悬浮的玻璃底板都按系统 Dock 校准。

## 功能

### iPhone 式分组

- **建组**：把一个 App 拖到另一个 App 图标的正中央，目标图标会长出文件夹底板并提示“松开创建分组”，松手就建好了。拖到图标边缘则是调整顺序。
- **打开**：单击分组，面板从图标上方展开，带一个指向分组图标的小箭头，每行 3 个 App。单击其中的 App 就打开或切换过去；还没运行的 App 会在面板里跳动，启动后面板自动收起。
- **收起**：按 Esc、点面板外面，或者再点一次分组图标。
- **整理**：在面板里拖动排序；把 App 拖出面板，放回应用栏；右键分组可以展开、重命名或解散。
- **管理分组**：在设置里打开“管理分组”窗口，可以给分组添加或移出 App、调整顺序、改名、解散。
- **不重复占位**：分组里的 App 运行时，分组图标下方会出现运行指示，不会在栏上再多出一个图标。

### 和系统 Dock 一样顺手

- 悬停放大（跟随系统 Dock 原来的“放大”设置）、名称提示、运行指示、启动动画、未读角标。
- 按下图标时照原生 Dock 变暗；App 暂时找不到时，图标上显示原生 Dock 的灰色问号。
- App 用自带的 Dock 图标插件画图标时（比如在 App 里换过图标），应用栏显示的也是它画的那个。
- **右键 App**：打开／切换、它当前的窗口、App 自带的 Dock 菜单项（比如访达的“新建‘访达’窗口”）和“选项”、在 Finder 中显示、保留在应用栏或移除、隐藏、退出、强制退出。
- **窗口预览**：指针在运行中的 App 上停一下，就会弹出它的窗口缩略图，最小化的窗口也显示真实画面。点缩略图切到对应窗口（最小化的会先还原），点 × 关闭窗口。应用栏和分组面板里都能用。
- **调整与移除**：拖动图标调整顺序；把图标拖出应用栏，看到“松开移出应用栏”时松手即可移除。
- **文件和文件夹**：把文件或文件夹拖到应用栏空白处，会变成右侧的入口；单击文件夹展开内容列表，可按修改时间或名称排序。从 U 盘、网络盘拖文件到文件夹入口时默认拷贝。
- **用 App 打开文件**：把文件拖到 App 图标上（包括分组面板里的 App），就用这个 App 打开。
- **最小化的窗口**显示在右侧；如果在系统设置里选择把窗口最小化到应用程序图标，则跟系统一样不单独显示。
- **废纸篓**会显示空或满；右键可以打开，或者清倒（清倒前会先弹出确认框）。
- 卸载的 App 约 10 秒后从应用栏移除；30 分钟内装回来，会自动回到原来的位置。

### 窗口不会被挡住

系统 Dock 隐藏后，已经打开的 App 会以为屏幕底部没有 Dock，把窗口一直铺到最底下。DockApex 会把铺满、平铺或伸进应用栏的窗口自动收短到应用栏上方，也会把伸进应用栏的小浮窗（比如语音输入条）挪开。双击标题栏缩放时，仍然可以在原尺寸和铺满之间来回切换。

### 设置与多显示器

右键应用栏空白处，或者点菜单栏的四格图标，可以设置：

- 管理分组；撤销布局更改（⌥⌘Z）
- 位置：底部、左侧、右侧
- 显示器：主显示器、所有显示器、跟随指针，或者指定某一块显示器
- 自动隐藏：移到屏幕边缘时唤出
- 显示最近使用的 App：关掉后，没固定的 App 退出就会从栏上消失
- 图标大小：28、37、48、64 点
- 登录时打开：开机自动打开 DockApex

## 隐私

- 分组、固定项顺序和偏好都只存在本机，应用本身不联网（“关于”里只有一个打开 GitHub 页面的链接）。
- 日常使用中，屏幕录制权限只用在下面几处，画面只在内存里，不存盘、不上传：
  - 窗口预览：只在你悬停时，把那个 App 的窗口逐个单独截成小缩略图；窗口关掉或 App 退出就丢掉，内存里最多留 64 张。
  - 读取 App 自带的 Dock 菜单项：右键时用一层实时画面盖住菜单弹出的那片区域约 1 秒，避免系统菜单闪出来。
  - 可选的“影子 Dock”：在应用栏下方补画背景。

## 开始使用

### 1. 下载安装

需要 Apple Silicon、macOS 14 及以上。

到 [Releases](https://github.com/DaliangPro/DockApex/releases) 下载最新的 `DockApex-版本号.dmg`，打开后把“DockApex”拖进旁边的“Applications”（应用程序）文件夹。

### 2. 第一次打开

DockApex 没有经过苹果公证，第一次打开时系统会提示无法验证开发者：

1. 在“应用程序”里双击“DockApex”，在提示框里点“完成”。
2. 打开“系统设置 › 隐私与安全性”，在页面下方找到关于“DockApex”的提示，点“仍要打开”，再确认一次。

之后就能正常打开。打开后，系统 Dock 会自动隐藏，应用栏出现在屏幕底部，原来 Dock 里的固定 App 会直接带过来。第一次启动时它会把自己加入登录项，开机自动打开。

### 3. 授权

在“系统设置 › 隐私与安全性”里打开下面几项：

| 权限 | 用途 |
| --- | --- |
| 辅助功能 | 窗口让位、浮窗避让、窗口列表与切换、菜单等 |
| 屏幕录制 | 窗口预览、读取 App 自带的菜单项；可选的“影子 Dock”也要用 |
| 自动化 › 访达 | 清倒废纸篓，第一次使用时才会询问 |

### 4. 退出、升级与卸载

- **退出**：点菜单栏的四格图标，或者右键应用栏空白处，选“退出”。退出时会自动恢复系统 Dock。
- **升级**：下载新版本的 DMG，先退出 DockApex，再把新版拖进“应用程序”替换旧版。分组和设置都会保留，已开的权限也不用重新授予。
- **卸载**：先退出，再把“DockApex”从“应用程序”拖进废纸篓。分组和设置在 `~/Library/Application Support/DockApex`，不再需要可以一并删除；登录项可以在“系统设置 › 通用 › 登录项”里移除。

### 从源码构建

需要 Apple Silicon、macOS 14 及以上、Xcode 命令行工具（Swift 6）和 Python 3。

```bash
git clone https://github.com/DaliangPro/DockApex.git
cd DockApex
bash build.sh
open build/DockFolders.app
```

从源码构建的版本把分组和设置放在项目目录的 `Data/` 里，请保留项目目录，不要单独挪走应用包。

想先跑一遍测试：

```bash
swift test -c release --scratch-path build/tests --cache-path build/package-cache
```

自己打安装包：`bash package.sh`，生成 `build/release/DockApex-版本号.dmg`。

## 常见问题

**原来的系统 Dock 去哪了？**
被设为自动隐藏，并挪到应用栏所在的屏幕，所以最小化窗口时仍会缩向屏幕底部。退出 DockApex 时，它会恢复原样。

**万一应用卡住或异常退出，怎么恢复原来的 Dock？**
异常退出时，随它运行的恢复助手会自动恢复系统 Dock。如果仍没恢复，重新打开 DockApex：它启动时会先把上次没收尾的设置恢复，再正常退出即可。从源码构建的版本也可以双击项目目录里的 `RestoreDock.command`，它不依赖主应用界面和辅助功能权限。

**为什么退出或重启 DockApex 后，最小化的窗口都回来了？**
进入和退出时都要重新载入系统 Dock，系统 Dock 重新载入时会把最小化的窗口全部还原。

**窗口为什么会自己变矮一截？**
这是“窗口让位”：把伸到应用栏下面的窗口底边收到应用栏上方，避免被挡住。新打开的 App 有时会先铺满、再被收短。

**没固定的 App 退出后，图标还留在栏上？**
那是“最近使用的 App”。右键应用栏空白处，取消勾选“显示最近使用的 App”即可。

**分组和设置存在哪里？**
安装版在 `~/Library/Application Support/DockApex/`，从源码构建的版本在项目目录的 `Data/`。包括分组、固定项顺序和偏好，不会上传到任何地方。

**还有别的显示方式吗？**
可以改用“影子 Dock”：系统 Dock 保持显示，负责屏幕占位和最小化动画的终点，应用栏叠在它上面。需要屏幕录制权限，用来在应用栏下方补画背景。

```bash
defaults write io.daliang.dockfolders useShadowDock -bool true
```

改完重启应用生效。

## 注意事项

- 应用会修改系统 Dock 的设置（自动隐藏、图标尺寸、固定项等），改之前会记下原值，退出时恢复。请尽量通过“退出”正常退出。
- 运行时有两个随主应用一起退出的恢复助手；第一次启动时会把自己加入登录项（可以在菜单栏图标的“登录时打开”或系统设置里关掉），不安装后台常驻服务。
- 用到的未公开系统接口包括系统 Dock 占位区（SkyLight）、CoreDock、辅助功能窗口编号等，macOS 升级后可能失效。

## 已知限制

- 系统预留区只能登记一块屏幕；“所有显示器”模式下，其他屏幕靠窗口让位来补。
- 已经打开的 App 读不到应用栏的占位，窗口只能事后收短，会先错后对。
- 第一次右键某个 App 时要先读取它自带的菜单项，约需 1 秒，之后 10 分钟内直接用缓存。
- 窗口预览和右键菜单用的是系统弹出框。在 5K 显示器上实测，它每次换位置或大小弹出时，系统会临时占用约 250 MB 图形内存，约 1 秒后释放。
- 部分自绘的 Dock 图标，以及全屏、多桌面的各种组合还没有全部覆盖。
